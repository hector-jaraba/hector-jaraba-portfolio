Performance is not just a feature—it's a fundamental aspect of user experience. Every 100ms of delay can cost you conversions, engagement, and revenue. Let's dive into practical performance optimization techniques.

## Measuring Performance

### Core Web Vitals

Focus on these three key metrics:

**Largest Contentful Paint (LCP)**: Measures loading performance. Aim for < 2.5s.

**First Input Delay (FID)**: Measures interactivity. Aim for < 100ms.

**Cumulative Layout Shift (CLS)**: Measures visual stability. Aim for < 0.1.

```javascript
// Measure Core Web Vitals
import { onCLS, onFID, onLCP } from 'web-vitals';

function sendToAnalytics({ name, value, id }) {
  const body = JSON.stringify({ name, value, id });
  navigator.sendBeacon('/analytics', body);
}

onCLS(sendToAnalytics);
onFID(sendToAnalytics);
onLCP(sendToAnalytics);
```

<Callout type="info" title="Real User Monitoring">
  Synthetic testing is useful, but real user monitoring (RUM) gives you the full picture of actual user experience.
</Callout>

## JavaScript Optimization

### Code Splitting

Split your JavaScript bundles intelligently:

```javascript
// Route-based splitting
const routes = [
  {
    path: '/dashboard',
    component: () => import('./Dashboard'),
  },
  {
    path: '/profile',
    component: () => import('./Profile'),
  },
];

// Component-based splitting for heavy components
const HeavyChart = lazy(() => import('./HeavyChart'));

function Analytics() {
  return (
    <Suspense fallback={<ChartSkeleton />}>
      <HeavyChart data={data} />
    </Suspense>
  );
}
```

### Tree Shaking

Ensure your imports are tree-shakeable:

```javascript
// ❌ Imports entire library
import _ from 'lodash';
const result = _.debounce(fn, 300);

// ✅ Imports only what's needed
import { debounce } from 'lodash-es';
const result = debounce(fn, 300);

// ✅ Even better: Import from specific path
import debounce from 'lodash-es/debounce';
const result = debounce(fn, 300);
```

### Minimize JavaScript Execution

Defer non-critical JavaScript:

```html
<!-- Critical JS: inline or high priority -->
<script>
  // Critical initialization code
  window.__INITIAL_STATE__ = {...};
</script>

<!-- Non-critical: defer -->
<script src="/analytics.js" defer></script>

<!-- Third-party: async or defer -->
<script src="https://widget.example.com/script.js" async></script>
```

### Lazy Loading

Lazy load images below the fold:

```typescript
// Native lazy loading
<img src="image.jpg" loading="lazy" alt="Lazy loaded" />

// Intersection Observer for custom loading
function LazyImage({ src, alt }: ImageProps) {
  const [isLoaded, setIsLoaded] = useState(false);
  const imgRef = useRef<HTMLImageElement>(null);

  useEffect(() => {
    const observer = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        setIsLoaded(true);
        observer.disconnect();
      }
    });

    if (imgRef.current) {
      observer.observe(imgRef.current);
    }

    return () => observer.disconnect();
  }, []);

  return (
    <img
      ref={imgRef}
      src={isLoaded ? src : 'placeholder.jpg'}
      alt={alt}
    />
  );
}
```

## CSS Optimization

### Critical CSS

Inline critical CSS for above-the-fold content:

```html
<head>
  <style>
    /* Critical CSS inlined */
    .hero { /* styles */ }
    .nav { /* styles */ }
  </style>
  <link rel="preload" href="styles.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
```

### Remove Unused CSS

Use PurgeCSS to eliminate unused styles:

```javascript
// postcss.config.js
module.exports = {
  plugins: [
    require('@fullhuman/postcss-purgecss')({
      content: ['./src/**/*.{js,jsx,ts,tsx}'],
      defaultExtractor: content => content.match(/[\w-/:]+(?<!:)/g) || [],
    }),
  ],
};
```

### Caching Strategy

Implement aggressive caching with proper cache busting:

```javascript
// Service Worker caching strategy
const CACHE_NAME = 'v1';
const ASSETS = ['/app.js', '/styles.css', '/logo.svg'];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS))
  );
});

self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      return response || fetch(event.request);
    })
  );
});
```

## Runtime Performance

### Debouncing and Throttling

Optimize expensive operations:

```typescript
// Debounce for input handlers
function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}

// Throttle for scroll handlers
function throttle<T extends (...args: any[]) => any>(
  func: T,
  limit: number
): (...args: Parameters<T>) => void {
  let inThrottle: boolean;
  return function(this: any, ...args: Parameters<T>) {
    if (!inThrottle) {
      func.apply(this, args);
      inThrottle = true;
      setTimeout(() => (inThrottle = false), limit);
    }
  };
}
```

### Virtual Scrolling

For long lists, use virtual scrolling:

```typescript
import { useVirtualizer } from '@tanstack/react-virtual';

function VirtualList({ items }: { items: any[] }) {
  const parentRef = useRef<HTMLDivElement>(null);

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 50,
  });

  return (
    <div ref={parentRef} style={{ height: '400px', overflow: 'auto' }}>
      <div style={{ height: `${virtualizer.getTotalSize()}px` }}>
        {virtualizer.getVirtualItems().map((virtualItem) => (
          <div
            key={virtualItem.key}
            style={{
              position: 'absolute',
              top: 0,
              left: 0,
              width: '100%',
              height: `${virtualItem.size}px`,
              transform: `translateY(${virtualItem.start}px)`,
            }}
          >
            {items[virtualItem.index].content}
          </div>
        ))}
      </div>
    </div>
  );
}
```

## Monitoring and Debugging

### Performance Observer API

Monitor performance in production:

```javascript
// Monitor long tasks
const observer = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    console.warn('Long task detected:', entry.duration);
    // Send to analytics
  }
});

observer.observe({ entryTypes: ['longtask'] });

// Monitor layout shifts
const clsObserver = new PerformanceObserver((list) => {
  for (const entry of list.getEntries()) {
    if (!entry.hadRecentInput) {
      console.warn('Layout shift:', entry.value);
    }
  }
});

clsObserver.observe({ entryTypes: ['layout-shift'] });
```

## Conclusion

Performance optimization is an ongoing process. The key takeaways:

1. **Measure first**: Use real user monitoring to understand actual performance
2. **Optimize critical path**: Focus on what affects user-perceived performance
3. **Progressive enhancement**: Ensure basic functionality works, then enhance
4. **Monitor continuously**: Performance regressions are easy to introduce
5. **Set budgets**: Prevent performance degradation with automated checks

A fast website isn't just about technology—it's about understanding user needs and optimizing for real-world conditions.
